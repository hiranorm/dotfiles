何かを調べて資料にまとめる際、参照したリンクは論文スタイルの番号付き引用形式で資料に含めるようにする。

## 引用スタイル

- 本文中で参照した箇所には `^1`、`^2` のように上付き番号を振る（Markdownの `^` 記法 or `<sup>1</sup>` タグ）
- 資料末尾に `## 参考文献` セクションを設け、番号順にリストアップする
- リンク（URL）はバッククォート（`）で囲まず、そのまま貼ってクリックで飛べる形にする

## 例

本文：

> vLLM はページドアテンションによってメモリ効率を大幅に改善した^1。OpenAI 互換の API サーバとしても動作する^2。

末尾：

```
## 参考文献

1. vLLM公式ドキュメント https://docs.vllm.ai
2. vLLM OpenAI互換サーバ https://docs.vllm.ai/en/latest/serving/openai_compatible_server.html
```

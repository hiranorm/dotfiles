# 記事の文体・記法ルール

ゆるディープの記事を書く際の、見た目・記法の統一ルール。

## 太字（`**...**`）と「」の併用

**「」（カギカッコ）の外側に `**` を置かない**。

- NG: `**「これ、いっぺんに開きたい」**` ← 「」の外側に ** が来ている
- OK: 「**これ、いっぺんに開きたい**」 ← 太字を「」の中に収める
- OK: 太字を諦める（「これ、いっぺんに開きたい」だけにする）

理由: 「」は単独で視線を集める強い記号で、その外側に太字を重ねると視覚的に過剰になり、強調の区切りも曖昧になる。「」を使った時点で十分に目立つので、その上から太字を被せない。

リスト項目の見出し（`- **名前**: 説明`）の「名前」に「」を含めたい場合も同様。太字を諦めるか、文言を変えて「」を外すかで対応する。

## その他の禁止表現

- 「って思いますよね」形式の共感文は使わない（CLAUDE.md 本体「記事タイトルの設計」セクションに既出）
